## Опис
Marketcheker е апликација за проверка и анализа на пазарни податоци.  
Проектот е структуриран со **backend** (Python/FastAPI), **frontend** (React), и **PostgreSQL** база.

## Технологии
- Python 3.10+
- FastAPI
- SQLAlchemy
- PostgreSQL
- React (Frontend)
- GitHub Actions (CI/CD)
